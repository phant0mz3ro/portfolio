Put local demo video files (.mp4, .webm) here.

Reference them in project frontmatter as an absolute path from the site root, e.g.:
  video: "/videos/atm-robot-car-demo.mp4"

For YouTube or Vimeo, just use the normal watch/share URL instead — no need to put
anything in this folder:
  video: "https://www.youtube.com/watch?v=XXXXXXXXXXX"
